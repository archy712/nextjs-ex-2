# QuickQuote (Notion 견적서 공유 서비스) MVP PRD

## 🎯 핵심 정보

**목적**: 1인 개발자/소규모 팀이 Notion에 입력한 견적서를, 클라이언트가 로그인 없이 웹에서 바로 확인하고 PDF로 받아갈 수 있게 한다.
**사용자**: 프리랜서·소규모 스튜디오 등 Notion으로 견적서를 관리하는 1인/소수 인원 공급자와, 그 견적서를 받는 클라이언트(발주자).

## 📌 가정 (Assumptions)

사용자가 구체적으로 명시하지 않은 부분에 대해, MVP 범위를 좁게 유지하기 위해 아래와 같이 가정한다.

1. **Notion은 읽기 전용 소스**: 이 서비스는 Notion 데이터베이스에 쓰기(생성/수정)를 하지 않는다. 견적서 작성/수정은 항상 Notion에서 직접 하고, 이 서비스는 조회만 한다.
2. **Notion 데이터 구조**: 공급자는 Notion에 "견적서" 데이터베이스 1개를 운영하며, 각 견적서는 하나의 데이터베이스 항목(페이지)이다. 품목별 라인아이템(품목명/수량/단가/소계)은 해당 견적서 페이지 내부의 표(테이블 블록) 또는 연결된 하위 데이터베이스로 표현된다고 가정한다. 견적서 항목(Property)에는 최소한 클라이언트명, 유효기간, 합계 금액이 포함된다.
3. **접근 제어 = 고유 링크(비밀번호 없음)**: 클라이언트는 회원가입/로그인 없이, 추측 불가능한 긴 랜덤 ID가 포함된 고유 링크로만 견적서에 접근한다. 별도 비밀번호 보호나 이메일 인증은 MVP 범위에 넣지 않는다(보안보다 편의 우선, 링크 유출 위험은 Out-of-scope 절에서 후속 보완).
4. **공급자만 인증 대상**: 로그인/회원가입은 견적서를 발행하는 공급자에게만 필요하다. 클라이언트는 인증 대상이 아니다.
5. **공급자용 관리 화면은 MVP에 포함하되 범위를 최소화**: 견적서 목록 조회, 공유 링크 복사, Notion 재동기화 정도만 제공한다. 견적서 상태(발송됨/열람됨/승인됨) 관리, 발송 이력, 알림 기능은 포함하지 않는다.
6. **PDF 생성 방식은 브라우저 인쇄 기능(`window.print()`) 채택**: 서버 사이드 렌더링 후 PDF 변환 라이브러리(Puppeteer 등)나 외부 PDF 서비스는 사용하지 않는다.
   - 이유: 견적서는 표 형태의 정적 문서라 `@media print` CSS만으로 충분한 품질이 나온다.
   - 서버 자원(헤드리스 브라우저 등)이나 별도 유료 API가 필요 없어 1인 개발/운영 부담이 가장 적다.
   - 클라이언트 브라우저가 기본 제공하는 "PDF로 저장"을 그대로 활용하므로 구현 범위가 작다.
7. **단일 통화(KRW), 단일 언어(한국어)** 가정. 다국어/다중 통화는 다루지 않는다.
8. **하나의 공급자 계정 = 하나의 Notion 연동(1개 Integration Token, 1개 데이터베이스)**. 여러 워크스페이스/여러 팀원 공유는 다루지 않는다.
9. **링크 전달은 서비스 밖에서 수동으로 이루어짐**(카카오톡, 이메일 등 공급자가 직접 복사해 전달). 서비스가 이메일을 자동 발송하지 않는다.

## 🚶 사용자 여정

### 흐름 A — 공급자 (견적서 발행 및 공유)

```
1. 랜딩 페이지
   ↓ "시작하기" 버튼 클릭

2. 회원가입 페이지 / 로그인 페이지
   ↓ 인증 성공

   [Notion 미연동 상태] → Notion 연동 설정 페이지 → 토큰/DB 연결 성공
   [Notion 연동 완료 상태] → (Notion 연동 설정 페이지 건너뜀)
   ↓

3. 대시보드 홈 (견적서 관리)
   ↓ 목록에서 견적서 선택 후 "링크 복사" 클릭

4. 완료 → 클립보드에 공개 링크 저장 → 클라이언트에게 서비스 외부 채널로 전달
```

### 흐름 B — 클라이언트 (견적서 열람 및 다운로드)

```
1. 공급자에게 받은 고유 링크 클릭
   ↓ (로그인 없이 바로 접근)

2. 견적서 열람 페이지
   ↓ 내용 확인 후 "PDF로 다운로드" 버튼 클릭

3. 브라우저 인쇄 다이얼로그 실행
   ↓ "PDF로 저장" 선택

4. 완료 → 로컬 PDF 파일 저장
```

## ⚡ 기능 명세

### 1. MVP 핵심 기능

| ID | 기능명 | 설명 | MVP 필수 이유 | 관련 페이지 |
|----|--------|------|-------------|------------|
| **F001** | Notion 견적 데이터 조회 | Notion API로 견적서 데이터(품목, 수량, 단가, 합계, 클라이언트명, 유효기간)를 읽어옴 | 서비스 전체가 의존하는 데이터 소스 연동 | Notion 연동 설정 페이지, 대시보드 홈, 견적서 열람 페이지 |
| **F002** | 견적서 목록 조회 | 공급자가 연동된 Notion 데이터베이스의 견적서 목록을 대시보드에서 확인 | 공급자가 자신의 견적서를 관리하기 위한 최소 기능 | 대시보드 홈 |
| **F003** | 견적서 공개 열람 | 클라이언트가 로그인 없이 고유 링크로 견적서 상세 내용을 확인 | 이 서비스의 핵심 가치(무로그인 열람) | 견적서 열람 페이지 |
| **F004** | 공유 링크 생성 및 복사 | 견적서마다 고유하고 추측 불가능한 공개 링크를 자동 생성하고 복사 | 클라이언트에게 견적서를 전달하는 유일한 통로 | 대시보드 홈 |
| **F005** | PDF 다운로드 | 브라우저 인쇄 기능을 이용해 견적서를 PDF로 저장 | 요청 사항에 명시된 핵심 산출물 | 견적서 열람 페이지 |
| **F006** | 유효기간 만료 표시 | 유효기간이 지난 견적서에 만료 안내 배너를 표시 | 견적서의 시의성을 클라이언트/공급자 모두에게 알림 | 대시보드 홈, 견적서 열람 페이지 |

### 2. MVP 필수 지원 기능

| ID | 기능명 | 설명 | MVP 필수 이유 | 관련 페이지 |
|----|--------|------|-------------|------------|
| **F010** | 기본 인증 | 공급자 회원가입/로그인/로그아웃만 지원 | 대시보드 접근을 위한 최소 인증 | 로그인 페이지, 회원가입 페이지 |
| **F011** | Notion 연동 설정 | Notion Integration Token과 데이터베이스 ID를 등록/수정하고 연결 상태 확인 | Notion 데이터 조회(F001)를 위한 전제 조건 | Notion 연동 설정 페이지 |
| **F012** | 견적서 데이터 새로고침 | 대시보드에서 버튼 클릭 시 Notion 최신 데이터를 강제로 재조회 | Notion에서 수정한 내용을 즉시 반영하기 위한 최소 장치 | 대시보드 홈 |

### 3. MVP 이후 기능 (제외)

- 견적서 상태 관리 워크플로우(발송됨/열람됨/승인됨/거절됨)
- 이메일/카카오톡 자동 발송 알림
- 링크 비밀번호 보호, 열람 시 본인 확인(이메일 인증 등)
- 유효기간 만료 시 자동 접근 차단(하드 블록) — MVP는 안내 배너만 표시
- 다국어 지원 및 다중 통화
- 전자서명/견적 승인 기능
- 열람 로그·조회수 통계, 클라이언트 행동 분석
- 여러 Notion 워크스페이스/여러 데이터베이스 동시 연동
- 팀/멀티유저 협업(공급자 계정 공유)
- 서버 사이드 PDF 렌더링(라이브러리 기반 고급 스타일링)

| **진입 경로** | 공급자가 공유한 고유 링크를 통한 직접 접근 (내비게이션 메뉴 없음) |
| **사용자 행동** | 품목별 품목명/수량/단가/소계 확인, 합계 금액·클라이언트명·유효기간 확인, "PDF로 다운로드" 버튼 클릭 |
| **주요 기능** | • 견적서 상세 렌더링(품목 테이블, 합계 금액, 클라이언트명, 공급자 정보, 유효기간)<br>• 유효기간 만료 시 안내 배너 표시<br>• **PDF로 다운로드** 버튼(브라우저 인쇄 다이얼로그 호출) |
| **다음 이동** | "PDF로 다운로드" → 브라우저 인쇄 다이얼로그에서 "PDF로 저장"(페이지 유지). 만료된 경우에도 열람은 가능하며 안내 배너만 표시 |

## 🗄️ 데이터 모델

> Notion이 견적서 원본 데이터(품목/수량/단가/합계)의 소스이며, 이 서비스는 해당 데이터를 자체 DB에 복제하지 않고 매번 Notion API로 조회한다. 자체 DB에는 계정 정보와 "공개 링크 ↔ Notion 페이지" 매핑만 최소로 저장한다.

### Users (공급자 계정)
| 필드 | 설명 | 타입/관계 |
|------|------|----------|
| id | 고유 식별자 | UUID |
| email | 로그인 이메일 | text (unique) |
| notion_api_key | Notion Integration Token | text (암호화 저장) |
| notion_database_id | 연동된 견적서 데이터베이스 ID | text |
| created_at | 가입일시 | timestamp |

### QuoteLinks (공개 링크 ↔ Notion 견적서 매핑)
| 필드 | 설명 | 타입/관계 |
|------|------|----------|
| id | 공개 링크에 사용되는 고유 식별자 | UUID |
| user_id | 소유 공급자 | → Users.id |
| notion_page_id | 대응되는 Notion 견적서 페이지 ID | text |
| client_name | 표시/캐시용 미러 필드 | text |
| expires_at | 표시/캐시용 미러 필드(유효기간) | date |
| created_at | 링크 생성일시 | timestamp |
